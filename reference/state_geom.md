# Australian State and Territory Geographical Boundaries

Spatial polygon data representing Australian states and territories,
based on the ABS Australian Statistical Geography Standard (ASGS).

## Usage

``` r
state_geom
```

## Format

An sf object containing state and territory polygons.

## Source

Australian Bureau of Statistics (ABS), ASGS Edition 3.

## Examples

``` r
data(state_geom)
nrow(state_geom)
#> [1] 9
```
